# سمورة 💗

موقع عربي/إنجليزي للتحفيز والمجاملات والدردشة اللطيفة، مبني باستخدام Flask وHTML وCSS وJavaScript ويرتبط بـ OpenAI API من الخادم الخلفي.

## التشغيل على Windows

1. ثبّت Python 3.10 أو أحدث.
2. افتح مجلد `Samoura_AI` في Terminal أو PowerShell.
3. أنشئ بيئة افتراضية وفعّلها:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

4. ثبّت المتطلبات:

```powershell
pip install -r requirements.txt
```

5. انسخ `.env.example` وسمّ النسخة `.env`، ثم افتح `.env` وضع مفتاحك مكان النص التوضيحي:

```env
OPENAI_API_KEY=ضع_مفتاحك_هنا
OPENAI_MODEL=gpt-4o-mini
PORT=5000
```

6. شغّل الموقع:

```powershell
python app.py
```

7. افتح `http://127.0.0.1:5000` في المتصفح.

## ملاحظات مهمة

- لا ترسل مفتاح API إلى أي شخص، ولا تضعه في ملفات HTML أو JavaScript.
- ملف `.env` مستثنى من Git عبر `.gitignore`.
- إذا لم يكن النموذج المحدد متاحًا في حساب API، غيّر `OPENAI_MODEL` إلى اسم نموذج متاح في حسابك.
- رسائل المحادثة تبقى في ذاكرة صفحة المتصفح فقط في هذه النسخة، ولا تُحفظ في قاعدة بيانات.
- عبارة التحفيز اليومية تُختار مرة واحدة لكل يوم وتُحفظ محليًا في المتصفح.
- قبل نشر الموقع للعامة، أضف تحديدًا لمعدل الطلبات (rate limiting)، وحدودًا للاستخدام والتكلفة، وHTTPS، وخادم إنتاج مثل Gunicorn أو منصة استضافة مناسبة. لا تستخدم خادم Flask التطويري للنشر العام.
